# Dataset Instructions

This directory contains the IBM Telco Customer Churn dataset used for this project.

## File Expected

The scripts expect the dataset to be located at `data/Telco-Customer-Churn.csv`.

## Downloading the Dataset

If the file is not present, you can download it directly from IBM's GitHub repository:

```bash
wget -O data/Telco-Customer-Churn.csv https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv
```

Alternatively, you can find the dataset on Kaggle:
[Kaggle: Telco Customer Churn](https://www.kaggle.com/blastchar/telco-customer-churn)
